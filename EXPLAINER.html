Impacto

Custo menor no direto — DeepSeek direto é mais barato que via OpenRouter (sem margem do agregador); cache-hit cobrado pela tarifa real (0.0028) em vez de input cheio.
Web app com escolha — o KeyModal do webapp estático deixa o usuário escolher OpenRouter ou DeepSeek; a chave nunca passa por servidor nosso (BYOK, CORS confirmado).
CLI/TUI provider-aware — ncrawl key set --provider deepseek, tela de chave na TUI, mensagens que nomeiam a variável certa.
Compat total — sem LLM_PROVIDER, tudo se comporta byte-idêntico a antes (verificado por revisão adversarial e testes).
TTS segue OpenRouter-only — a DeepSeek não tem API de áudio; decisão documentada no README/skills.

Premissas inferidas sem perguntar

O orquestrador operou em autonomia total: nenhuma pergunta foi feita ao usuário. Toda premissa assumida fica registrada aqui.

  • LLM_PROVIDER explícito, sem auto-detecção — mesmo com DEEPSEEK_API_KEY no ambiente, o provider só troca por env explícito; previsibilidade > conveniência.
  • json_object no direto — a API DeepSeek rejeita json_schema (400 confirmado por probe real); o degrade + retry/parse defensivo existentes cobrem o pior caso.
  • Custo local no ledger via injeção — computeUsageCost injeta usage.cost antes do resv.commit; budget.js ficou INTOCADO (nenhum risco de regressão no orçamento).
  • Effort colapsa no direto — xhigh/medium não existem na DeepSeek direta (mapeiam p/ high); omite-se o parâmetro reasoning por inteiro (contrato da API).
  • TTS permanece OpenRouter-only — DeepSeek não tem API de áudio; o player do webapp comporta "sem chave" quando só há chave deepseek.
  • Troca de provider em runtime não persiste LLM_PROVIDER — key set --provider deepseek salva só a chave; após restart o provider volta ao env (documentado).
  • Telemetria do crawl.js mudou de bytes no default — model_used vira o slug completo deepseek/deepseek-v4-flash-0731 (o que o runtime usa) em vez do hardcoded cru; achado do revisor aceito (valor antigo era inválido nos dois mundos).
  • Browser E2E do webapp substituído — o E2E completo custaria ~$0.18-0.20 no snapshot (4188 artigos); substituído por: código de produção do webapp com payload real + CORS provado por preflight + 123 testes; procedimento manual documentado.
  • Preços peak/off-peak pós-16/08 — revisão anunciada p/ 2026-08-16 16:00 UTC; env overrides cobrem o CLI, webapp exige código+deploy; nota de re-verificação registrada (não-bloqueante).
  • Test-onda1-provider-core absorvido — os 3 arquivos de teste entraram via fix-custo-cache + fix-gate-tests (conteúdo idêntico/superseded); drop sem merge para não duplicar.
