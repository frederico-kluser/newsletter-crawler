🚫 maxPages sem limite · isUrlKnown como freio

2026-08-05 · commit ce718e5

Problema

O fix anterior (maxPages=1 para fontes index sem --since explícito) capava a paginação na primeira página. Se uma fonte publica 30 itens/dia e o crawler fica 2 dias sem rodar, notícias na página 2 ficavam invisíveis. O isUrlKnown foi construído exatamente para ser o freio — mas nunca chegava a agir porque a paginação parava antes.

Mudança
// Antes:
const maxPages = isIndex
    ? opts.sinceDate && !opts.sinceIsDefault
      ? Math.max(source?.max_index_pages ?? 1, SINCE_MAX_INDEX_PAGES)
      : source?.max_index_pages ?? (opts.maxPages === Infinity ? 1 : opts.maxPages)
    : opts.maxPages ?? Infinity;

// Depois:
const maxPages = isIndex
    ? source?.max_index_pages ?? opts.maxPages ?? Infinity
    : opts.maxPages ?? Infinity;

Sem limite artificial. O crawler anda até uma das 5 paradas disparar:

  1. isUrlKnown 100% — todos os links já capturados
  2. added === 0 — todos na frontier
  3. below > 0 — data abaixo do --since
  4. Hash repetido — mesma página 2x
  5. findNextPage null — sem próxima
