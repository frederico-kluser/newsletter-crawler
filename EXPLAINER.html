Premissas inferidas sem perguntar

O orquestrador operou em autonomia total: nenhuma pergunta foi feita ao usuário. Toda premissa assumida fica registrada aqui.

  • Fonte única = Node Weekly — 1ª fonte de fábrica Cooperpress (tipo index); "últimos 3 dias" = --since 2026-08-11 (piso documentado).
  • Âncora da issue é a semana da newsletter — item curado pertence à SEMANA da issue, mesmo que o alvo tenha data própria mais antiga; por isso o backfill sobrescreve até a data "legítima" do alvo (inngest 07-13).
  • Retry de zod pelo shape ESTRITO — chave tolerada ausente re-amostra em vez de virar default silencioso na 1ª tentativa; default só esgotados os retries (sem isso a 637 viraria seção vazia sem tentativa).
  • reextract NUNCA sobrescreve com página de erro — guards isErrorPage/isBlockedPage + keepAggregatorVersion + --limit default 20 (varredura completa exige --all); achado da revisão adversarial aceito e corrigido.
  • "Truncamento" da Vitest era UI, não perda — a investigação com a página real provou que o corpo terminava mesmo no botão; o fix virou strip do gatilho + container quando mais longo.
  • Falso-positivo estreito da heurística de nav-menu aceito — suspect é advisory e o reclean conserta; a classe real (prosa com separadores) é estreita e documentada.
  • Quedas de tag remanescentes = aceitas por design — typescript/javascript/postgresql/docker/ai-agents existem em OUTRAS facetas (facet-mismatch é o modelo errando a faceta, não vocabulário faltando); bun ficou como sugestão futura.
  • Testing subwaves não criadas — os fixes vieram com 31 testes próprios + wire tests + revisões adversariais; subwaves separadas seriam duplicação.
  • Acidente de --help documentado — crawl --help inicia crawl (pré-existente); run 2 marcado failed, frontier restaurado, custo US$ 0,0147 fora das provas; recomendação de fix do parse registrada para fora.
